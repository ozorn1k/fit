# Фитнес-приложение

Одно приложение для Юли: программа от тренера, дневник питания, заметки, вес — и отчёт тренеру.
Работает без интернета, все данные лежат на телефоне.

## Что внутри

| Файл | Зачем |
|---|---|
| `index.html` | само приложение |
| `report.html` | страница отчёта, которая открывается по ссылке |
| `styles.css` | оформление |
| `js/store.js` | хранилище, утилиты, мост в Telegram |
| `js/food-db.js` | база продуктов (~160 позиций, ккал и БЖУ на 100 г) |
| `js/parser.js` | разбор текста программы от тренера |
| `js/workouts.js` | программы, ведение тренировки, история |
| `js/food.js` | дневник питания |
| `js/food-plus.js` | штрихкоды, повтор приёмов, свои приёмы, вода |
| `js/stats.js` | рекорды, графики по упражнениям, стрик, календарь |
| `js/timer.js` | секундомер и таймер обратного отсчёта |
| `js/notes.js` | заметки, вес, замеры, профиль, копия данных |
| `js/report.js` | сборка отчёта: текст + ссылка |
| `sw.js` | офлайн-кэш |
| `version.txt` | номер сборки, по нему приложение ловит, что открылось старым |
| `manifest.json`, `icon-*.png` | ярлык на экране телефона |

## Как это работает

**Программа тренировок.** Тренер пишет как обычно в мессенджере — Юля копирует сообщение
целиком и вставляет в приложение. Парсер разбирает «День 1 — ноги», «1. Приседания 4х12 40 кг»,
«3 подхода по 15», «Планка 3х45 сек», «Отдых между подходами 90 сек», комментарии в скобках.
Что не распозналось — правится руками в редакторе перед сохранением.

**Тренировка.** Открыла день → отмечает подходы. Поля веса и повторов заполнены не планом,
а тем, что реально было в прошлый раз — перебивать ничего не нужно. Показывает прошлые
результаты и подсказку о прибавке, если прошлую тренировку закрыла легко. Побила рекорд —
на экране всплывает 🏆. После отмеченного подхода запускается таймер отдыха; для планки
и кардио есть отдельный отсчёт. Отдельно живёт **секундомер и таймер** — кнопка на экране
тренировок и внутри тренировки: счёт вверх для планки и обратный отсчёт с пресетами.
В конце — самочувствие и комментарий тренеру.

**Рекорды и календарь.** По каждому упражнению — личный рекорд, расчётный 1ПМ, график
динамики и история по тренировкам. Упражнения без веса (планка, отжимания) считаются
по повторам и секундам. Календарь показывает серию дней подряд и что было в каждый день.

**Питание.** Поиск по базе (178 позиций, включая украинские магазинные) → граммы или
готовая порция → калории и БЖУ считаются сами. Плюс:
- **штрихкод** — камера читает код, продукт подтягивается из Open Food Facts и остаётся
  в локальном кэше, так что второй раз работает и без интернета;
- **«как в прошлый раз»** — повторяет тот же приём из любого из последних дней;
- **«мои приёмы»** — сохранённые комбинации добавляются одним тапом;
- «просто ккал» для кафе и «своё блюдо» для домашней еды;
- счётчик воды;
- любую запись можно открыть и поправить: граммы тянут за собой калории и БЖУ,
  цель по калориям меняется тапом по верхней карточке.

**Отчёт.** Профиль → «Собрать отчёт». Период на выбор. Два выхода:
- **текстом** — оформленный по разделам, уходит в чат одним тапом;
- **ссылкой** — открывает `report.html` с оформленной страницей.
  Данные упакованы прямо в ссылку (deflate + base64 в hash), сервер и база не нужны.
  Неделя укладывается примерно в 1200 символов.

## Запуск локально

```bash
python -m http.server 8777
```

Дальше `http://127.0.0.1:8777/index.html`.

## Как поставить Юле на телефон

Нужен HTTPS-адрес (без него не работают ярлык на экране и офлайн-кэш).
Подойдёт любой статический хостинг: Vercel, Netlify, GitHub Pages, Cloudflare Pages.

1. Залить папку целиком.
2. На телефоне открыть адрес в Chrome → меню → «Добавить на главный экран».
3. Дальше открывается как обычное приложение, интернет больше не нужен.

## Как сделать из этого Telegram Mini App

1. В Telegram написать [@BotFather](https://t.me/BotFather) → `/newbot` → задать имя.
2. `/newapp` → выбрать бота → указать адрес, куда залито приложение.
3. Юля открывает бота → кнопка → приложение внутри Telegram.

Приложение само определяет, что запущено внутри Telegram: подхватывает системную кнопку
«Назад», вибро-отклик и подставляет имя из профиля. Вне Telegram всё работает так же.

## Как выкатывать обновления

GitHub Pages отдаёт HTML с десятиминутным сроком жизни и заголовками управлять не даёт,
поэтому при каждом деплое нужно менять номер сборки **в двух местах сразу**:

1. `BUILD` в начале `js/main.js`
2. `version.txt` — то же самое значение

Приложение на старте сверяет их и, если на сервере лежит новее, один раз перезагружается.
Без этого обновление доходило бы до телефона с задержкой и выглядело бы как «ничего не поменялось».

## Данные

Всё в `localStorage` телефона. Синхронизации между устройствами нет — это плата за
работу без интернета. Раз в пару недель стоит нажимать «Сохранить копию» в профиле:
скачивается JSON-файл, из которого всё восстанавливается на новом телефоне.
