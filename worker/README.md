# Короткие ссылки на отчёт

Приложение работает офлайн и без этого Worker — он нужен только в момент «поделиться отчётом».
Без него ссылка просто останется длинной (~680 символов), всё остальное не меняется.

## Что он делает

1. Приложение отправляет упакованный отчёт (тот самый хвост после `#`) в `POST /s`
2. Worker кладёт его в KV под коротким кодом и возвращает ссылку вида `https://…/aB3xK`
3. Тренер открывает её — Worker редиректит на `report.html#<отчёт>`

Сам отчёт Worker не разбирает и не расшифровывает: для него это просто строка.
Записи живут год, потом исчезают сами.

## Уже развёрнут

`https://fit-report.karmannyy.workers.dev` — адрес прописан в приложении по умолчанию,
вставлять вручную ничего не нужно. Ниже — как поднять заново или на другом аккаунте.

## Развернуть (5 минут, нужен аккаунт Cloudflare)

Из папки `worker`:

```bash
npx wrangler login
```

```bash
npx wrangler kv namespace create REPORTS
```

Команда напечатает `id = "..."` — подставь его в `wrangler.toml` вместо заглушки.

```bash
npx wrangler deploy
```

В конце выведется адрес вида `https://fit-report.<твой-аккаунт>.workers.dev`.

## Подключить к приложению

Открыть приложение → **Профиль** → **Короткие ссылки** → вставить этот адрес
(для уже развёрнутого он подставлен по умолчанию).
Дальше кнопка «Ссылка на красивый отчёт» будет отдавать короткую ссылку,
а если интернета нет или Worker недоступен — молча вернётся к длинной.

## Что стоит понимать

- Отчёты Юли лежат в твоём Cloudflare KV. Кто угадает код — увидит отчёт,
  поэтому коды случайные, а не по порядку.
- Бесплатного тарифа хватает с огромным запасом: лимит 1000 записей в день,
  один отчёт — одна запись.
- Удалить конкретный отчёт: `npx wrangler kv key delete --binding REPORTS <код>`
